# AI Usage

## What AI tools used and what for

50% ChatGPT through its web interface, 50% Github Copilot through Visual Studio 2026. 

ChatGPT is used to analyze the take home test doucment, brainstorm ideas and get some suggestions.

Github Copilot is used to generate codes and web pages.

## One place where AI helped me to move faster

Given detailed instructions, Github Copilot really helped me to generate codes real fast since it was able to directly access and analyze the whole codebase, and understand the context of the code too.

## One place where you disagreed with, corrected, or rejected AI output

When brainstorming for ideas and solutions, ChatGPT suggested somewhat complex and "near ideal" solution that may fit for production application. After manually looking for other references and my previous projects, I came up with much simpler solution and ChatGPT conveniently just agreed with me.

ChatGPT also suggested me with certain data models but some of them have no real use so I just removed or simplified it. 

## What you would change about your AI workflow if you had to do this again

I think I would asked AI to generate me some unit tests and setup agents to generate test cases and automate testing.

## How to verify final implementation

The way I verify the final implementation is basically to build and run locally, then deploy and test it on an actual live server.
